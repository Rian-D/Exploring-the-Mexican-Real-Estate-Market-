# Exploring the Mexican Real Estate Market

## Overview

Across four notebooks, I loaded, cleaned, and visualised property listings, then quantified relationships among variables using correlation analysis. One question runs through the whole project: **is price driven more by size or by location?** The work here builds the groundwork for the predictive modeling in Project 2.

## What I Learnt

- **Data wrangling with pandas** — work with real tabular datasets, clean messy data, and compute descriptive statistics.
- **Visualization** — build histograms, box plots, and scatter plots to explore distributions and relationships among variables.
- **Correlation analysis** — compute and interpret Pearson correlation coefficients, including group-level analysis by state and property type.
- **Evidence-based conclusions** — analyze price per square meter across locations to weigh the relative influence of size vs. location.
